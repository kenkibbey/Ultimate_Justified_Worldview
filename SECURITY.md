# Security, privacy and confidential material

**Do not post passwords, security tokens, private addresses, medical information, protected community knowledge, sensitive witness narratives, or other confidential material in a GitHub issue.** GitHub issue text and accounts are visible to the public.

No confidential UJW reporting channel has yet been verified or announced. For now, do **not** disclose sensitive material here. The maintainers must establish and test a suitable private contact method before promising confidential intake.

Report non-sensitive errors in public methods, citations, privacy warnings or links using the general challenge form. Public claims will omit protected details and use permissible evidence summaries where possible.
